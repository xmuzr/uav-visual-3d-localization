# 数据准备与公开范围

## 公开文件

公开版本包括原有 Python 算法、HTML / CSS / JavaScript 界面、依赖清单、配置模板、合成演示与说明文档。

原始航拍照片、`dji.md`、照片索引、Office 技术与验收文档、演示 PPT、佐证工作目录及离线 wheel 留在本地，由 `.gitignore` 排除。照片与元数据可能包含精确位置、采集时间及设备标识。

## 自有照片

1. 将照片放入 `数据集/原始照片/`，或者在界面选择自己的目录。
2. 核对相机内参、图像尺寸、像素坐标、GPS 与云台位姿。优先使用标定值；估计焦距需要单独评价误差。
3. 若图像缺少部分 DJI 元数据，可提供 ExifTool 风格的 `数据集/dji.md`；段落以原始照片文件名匹配。元数据匹配与一致性诊断应逐项核对。
4. 多视图必须在至少两张照片上点击同一静止物理点。配置中的图像中心像素仅为占位值。
5. LRF 高度平面需要至少 3 个有效且不共线的落点，并检查距离门控、表面类别和空间分布。

`multi_view_cli.py` 中的相对图像路径以 JSON 配置文件所在目录为基准。可以直接修改现有配置模板，也可以在本地复制后修改路径。

## 合成数据

`examples/synthetic_demo.py` 直接构造相机内参、ENU 位姿、目标和高度平面，使用固定随机种子生成像素噪声。它调用正式核心模块，不读取现场照片或元数据。

两个单图配置中的内参、控制点和经纬度原点均为演示参数。合成结果仅用于复现实例和检查计算链路。

## 精度评价

实测结果应使用未参与相机标定、控制点拟合或 LRF 平面拟合的独立真值。建议分别报告水平误差、高程误差、3D 误差和样本数量，并记录相机距离、姿态、地面坡度、交会几何与真值测量方法。拟合残差和射线残差不能替代这些误差。
