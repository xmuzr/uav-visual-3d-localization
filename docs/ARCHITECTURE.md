# 架构与坐标约定

## 模块分工

`image_localization.py` 实现基础几何；`multi_view_localization.py` 在相同的 ENU 坐标定义下扩展多视图交会和高度平面。两个 CLI 负责配置解析与输出；Flask 应用负责本地照片、元数据读取及交互。核心算法不依赖飞控或 ROS。

## 坐标

- 像素：`[u, v]`，向右、向下为正。
- 相机坐标：右、下、前；内参为 `fx, fy, cx, cy`。
- 局部世界坐标：ENU，`[East, North, Up]`，单位为米。
- 地理坐标：纬度、经度使用度，高度使用米；转换通过 WGS84 ECEF 与局部 ENU 完成。
- `camera_to_enu` 为相机到 ENU 的右手正交旋转矩阵。
- `heading_deg` 从北顺时针；`tilt_from_nadir_deg=0` 为垂直向下。DJI 云台角与这一约定不同，由元数据适配函数处理。

AGL 是相对地面的高度，高度字段的具体基准必须按数据来源核对。不能把相对高度、海拔高度及椭球高度直接混用。

## 单图几何

像素经去畸变及内参归一化后得到相机射线，旋转到 ENU：

$$d = R_{camera\to ENU}\,\mathrm{normalize}(K^{-1}[u,v,1]^T), \qquad P(t)=C+td.$$

水平面求交使用给定的 `plane_z`。DEM 求交以规则格网提供高度查询。GCP 分支使用同一平面上的控制点估计单应矩阵；拟合控制点和独立检查点的残差分别报告。

## 多视图

每张图提供相机中心 $C_i$、单位方向 $d_i$ 和正权重 $w_i$。目标点最小化：

$$\sum_i w_i \lVert (I-d_i d_i^T)(P-C_i)\rVert^2.$$

输出包括垂直射线距离、交会角、法方程条件数、相机后方解的计数及质量提示。质量标签是启发式诊断，不能解释为统计置信度或实测精度等级。

## LRF 高度平面

有效落点拟合 `z = a*x + b*y + c`，再与目标射线求交。可配置按残差剔除的迭代过程。落点应覆盖有足够范围的同一局部表面；近共线点、立面、跨表面点或错误测距会使模型不可靠。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /` | 交互界面 |
| `GET /api/photos` | 读取本地照片列表 |
| `GET /api/image` | 返回选定照片 |
| `GET /api/metadata` | EXIF / XMP 与补充元数据 |
| `POST /api/localize` | 主界面的单像素定位 |
| `POST /api/multi-view/localize` | 多照片同名点交会 |

独立多帧应用只提供对应的照片与交会接口。运行器默认绑定 `127.0.0.1`，关闭调试和自动重载。
